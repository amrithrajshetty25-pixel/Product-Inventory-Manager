PRODUCT INVENTORY MANAGER

Files:
- src/inventory.ts
- src/function.ts
- src/Products.ts
- src/errors.ts
- index.html
- style.css
- tsconfig.json

Run:
1. Open terminal in the project folder.
2. Run: npx tsc
3. Open index.html using a local server.

The application supports:
- Add Product
- Search Products by name or tag
- Show All
- Available Only
- Remove Product with confirmation
- Stock Status
- Product Count
- Discounted Price
